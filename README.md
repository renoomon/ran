# 🎬 سينيسيرش — CineSearch

**موقع بحث للأفلام والمسلسلات فكرته إنك ما تحتاج تذكر الاسم.**
اكتب وصف القصة اللي عالق في بالك، والموقع يطلع لك العمل + كل الأعمال المشابهة، بالبوستر والقصة الكاملة، وروابط مباشرة لـ IMDb و18 موقع ثاني.

## 🔑 مفتاح TMDB

الموقع فيه **مفتاح مشترك مثبّت** في `assets/js/config.js` (`sharedKey`)، فيشتغل كامل لكل زائر بدون أي إعداد.

> ⚠️ لأن الموقع يشتغل في المتصفح، المفتاح المشترك ظاهر لأي زائر (في الكود وفي تبويب الشبكة). هذا وضع طبيعي لمفاتيح TMDB v3 — هي للقراءة فقط وما تعطي أي صلاحية على الحساب — بس معناها إن أي أحد يقدر ينسخه ويستخدمه على حصتك. لو صار استهلاك غير طبيعي، بدّل قيمة `sharedKey`.

### مفتاح خاص فيك (اختياري)

1. سجّل في [themoviedb.org/signup](https://www.themoviedb.org/signup)
2. اطلب مفتاح من [Settings ← API](https://www.themoviedb.org/settings/api)
3. افتح الموقع ← زر ⚙️ ← الصق المفتاح ← حفظ

يقبل **مفتاح v3** (32 خانة) أو **توكن v4 Bearer**، ويتجاوز المفتاح المشترك. ينحفظ في `localStorage` في متصفحك فقط، وما ينرسل لأي جهة غير TMDB.

## 🈯 كيف يوصلك الملخص بالعربي

بالترتيب، وأول ما ينجح يتوقف:

1. 🥇 **ملخص TMDB بـ `ar-SA`** — لو موجود
2. 🥈 **`translations` من TMDB** — أي ترجمة عربية رسمية (`ar-SA` ← `ar-AE` ← `ar-EG`)
3. 🥉 **ترجمة آلية** للملخص الإنجليزي عبر [MyMemory](https://mymemory.translated.net/) — تُعلَّم بوضوح «(ترجمة آلية)» وتُخزَّن في متصفحك عشان ما تتكرر
4. 📖 **قسم القصة من ويكيبيديا** — عربية أولًا، وإذا ما فيه مقالة عربية يجيب الإنجليزية ويعرض زر **«ترجم القصة الكاملة للعربية»** (يدوي، عشان ما يستهلك الحصة اليومية بدون طلبك)

حد الترجمة المجاني ٥٠٠٠ حرف يوميًا، ويصير ٥٠ ألف لو حطيت بريدك في الإعدادات.

```

                             │
              ┌──────────────┼──────────────┐
              │              │              │
        محرك الاسم      محرك القصة      محرك الثيمة
   TMDB /search/multi   ويكيبيديا AR+EN   TMDB /search/keyword
              │         (بحث نص كامل)          │
              │              │            /discover
              │        مطابقة مع TMDB          │
              │        (الاسم + السنة)          │
              └──────────────┼──────────────┘

                    (العمل اللي يطلع من أكثر
                     من محرك ترتفع درجته)

                       ترتيب وعرض
```

**درجة الترتيب** تجمع: قوة المطابقة في المحرك + تطابق الاسم + الشهرة + التقييم + مكافأة الظهور في أكثر من محرك.
